# Prova do modo sombra (05/11/2026)

Este arquivo é só texto, em `docs/`. Ele existe para duas coisas ao mesmo tempo:

1. provar que o **mesclador** mescla sozinho uma PR dentro da faixa;
2. provar que o **modo sombra** anota o veredito dessa PR sem mexer em nada.

O registro vai para o ramo `sombra/registro`, num arquivo por PR. Nada aqui depende de
ninguém clicar em botão — se este texto aparecer na `main` e o registro aparecer no ramo,
as duas peças funcionaram em produção.

## O que este arquivo não prova

Que o julgamento do degrau 4 presta. Um registro é um caso; o portão 2 pede trinta, e sem
nenhum incidente. Este arquivo é o primeiro tijolo, não a parede.
