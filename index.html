🔑 Acesso

Para esta página ler e escrever nas suas conversas privadas, ela precisa de um token de acesso do GitHub — guardado apenas neste navegador, nunca aqui no site.

  1. Abra github.com/settings/personal-access-tokens/new (entre na conta reboclbrank-max)
  2. Token name: chat-site · Expiration: 90 dias (ou o que preferir)
  3. Repository access: Only select repositories → marque agente
  4. Permissions: em Repository permissions, ache Issues e mude para Read and write
  5. Generate token → copie o valor (começa com github_pat_) e cole abaixo

📱 Instalar como aplicativo

No celular, use o menu do navegador → “Adicionar à tela de início”. O chat abre em tela cheia, como um app.

🎙 Voz

Toque no microfone para falar e no 🔊 das respostas para ouvir. Funciona melhor no Chrome/Android.

🎨 Aparência

Tema claro ou escuro — fica salvo neste aparelho.

🧠 Cérebro 100% local (offline)

Ligue o modo local (botão 🧠 no topo da conversa) e o chat passa a responder com um modelo que roda dentro do seu navegador — depois do 1º uso funciona sem internet e não envia nada para lugar nenhum. É o cérebro reserva do seu assistente: se todos os motores online caírem, o seu aparelho ainda conversa com você.

Na primeira vez baixa ~1,1 GB (depois fica salvo neste navegador). Precisa de navegador com WebGPU (Chrome/Edge no computador ou Android). Em aparelho fraco pode ficar lento — é opcional.

As trocas do modo local ficam só no aparelho até você apertar ☁️ para sincronizar com o GitHub (o assistente arquiva sem responder de novo).
