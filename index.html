🔑 Acesso

Para esta página ler e escrever nas suas conversas privadas, ela precisa de um token de acesso do GitHub — guardado apenas neste navegador, nunca aqui no site.

  1. Abra github.com/settings/personal-access-tokens/new (entre na conta reboclbrank-max)
  2. Token name: chat-site · Expiration: 90 dias (ou o que preferir)
  3. Repository access: Only select repositories → marque agente
  4. Permissions: em Repository permissions, ache Issues e mude para Read and write
  5. Generate token → copie o valor (começa com github_pat_) e cole abaixo
Página pública (não contém dados). Suas conversas ficam no repositório privado reboclbrank-max/agente.
